# Guide utilisateur
- **Client** : parcourir la boutique (filtres, tri), ajouter au panier, commander (paiement à la livraison ou carte *simulée*), suivre ses commandes, annuler (tant que « PENDING »), demander un remboursement, laisser un avis.
- **Repas** : choisir un restaurant, personnaliser avec suppléments, commander (un seul restaurant par commande, minimum de commande respecté).
- **Vendeur** : *Espace pro* → ajouter/supprimer ses produits, voir statistiques, faire avancer ses commandes.
- **Restaurateur** : voir les commandes, confirmer/préparer/marquer prêt.
- **Livreur** : accepter une course « READY_FOR_PICKUP », puis récupérer et livrer.
- **Admin** : statistiques, suspension de comptes, coupons (API).
